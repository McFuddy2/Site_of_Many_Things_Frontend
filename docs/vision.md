# Vision

## Project Purpose

The Site of Many Things exists to become a magical, clean, powerful ecosystem of TTRPG tools that empower Dungeon Masters and players.
It aims to make session management easier, prep faster, creativity endless, and the experience delightful.

This project began as a portfolio piece and a hedge against a shifting job market — and became something worth building for its own sake. Glenn works full time, which means the project no longer carries emergency financial pressure. The immediate revenue goal is $50/month to cover hosting costs, then steady growth toward meaningful supplemental income from there.

This is a long-term asset, a creative outlet, a community resource, and a supplemental income stream that we intend to grow steadily into something significant.

---

# Long-Term Vision

The Site of Many Things will grow into a large, interconnected suite of DM tools including:

- Initiative tracker
- Combat manager
- Spell searcher
- NPC, item, and quest generators
- Encounter builder

The future includes:

- AI-driven DM assistance

# Financial Milestones
These are ordered stepping stones, not arbitrary targets. Each one is a real celebration.

## Milestone 1 — First Dollar
The psychological breakthrough. Proof that strangers value what we built enough to pay for it.
Strategy: Ko-fi visibility, genuine Reddit presence, tools that are actually good.

## Milestone 2 — Break Even ($50/month)
Cover the cost of running the site. Every dollar after this is profit.

## Milestone 3 — First Real Signal ($100/month)
Proof the revenue model works. AdSense approved and running. Ko-fi converting.

## Milestone 4 — Meaningful Supplement ($500/month)
The site is a real side income. Traffic is compounding. Tools are being shared organically.

## Milestone 5 — The Refinance Number ($1,500/month)
The most personally meaningful near-term target. This is the number that changes Glenn and Jess's financial breathing room.
Strategy: Consistent traffic, AdSense + Ko-fi + Patreon tier, 3+ differentiated tools live.

## Milestone 6 — Real Business ($3,000/month)
The site is a meaningful business. Caleb could potentially earn consistent income contributing here.
Strategy: Subscriptions, more tools, growing email list, stronger SEO footprint.

## Milestone 7 — Replace a Salary ($6,000/month)
The site supports one person working on it seriously. Major tool ecosystem in place.

## Milestone 8 — Full Scale ($12,000/month)
The original dream. Multi-tool ecosystem, subscriptions, digital products, partnerships.
This is achievable. It is just not the first goal.

# Current Competitive Advantages

These are real and should be protected and marketed:

- The spell searcher is the most complete 5e spell search tool publicly available, and the only one capable of filtering by class exclusion (e.g. Wizard and Bard spells NOT on the Cleric list).

These advantages are the foundation of all traffic and monetization strategy.

# Guiding Principles

### 1. Magical + Clean
Every tool should feel arcane and delightful, but never cluttered or confusing.

### 2. MVP First
Release the smallest useful version. Polish later.

### 3. Traffic Before Monetization
Monetization only works at scale. Getting discovered comes first.

### 4. Monetization Conscious
Features should support SEO, recurring usage, subscription value, ad revenue, and email list growth.

### 5. Sustainable Growth
Build tools that are maintainable, extensible, and can support future team members.

### 6. Community Value
The platform should feel like it genuinely empowers DMs and helps them run better sessions.
