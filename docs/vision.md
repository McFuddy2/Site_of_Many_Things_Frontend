# Vision

## Project Purpose

The Site of Many Things exists to be a magical, clean, powerful ecosystem of free tools for Dungeon Masters and TTRPG players.

It aims to make session management easier, prep faster, and the experience at the table more enjoyable — for both the DM and the players.

The tools are free and intended to stay free. The first financial goal is for the site to cover its own running costs — approximately $15/month — through ads and supporter contributions. Everything beyond that is growth.

---

## Long-Term Vision

The Site of Many Things will grow into a large, interconnected suite of DM tools including:

- Initiative Tracker
- Combat Manager
- Spell Searcher
- Encounter Builder
- NPC, item, and quest generators
- Campaign Manager
- User accounts and shared content
- Eventually: mobile apps, VTT integrations, and a marketplace

---

## Current Competitive Advantages

These are real and should be protected and built upon:

- The Initiative Tracker is built for the whole table — players and DM simultaneously — not just the DM.
- The Spell Searcher supports class exclusion filtering (e.g. Wizard spells NOT on the Cleric list) — a capability most tools don't offer.
- The Spell Searcher covers spells across 16+ official 5e source books.

## Guiding Principles

### 1. Magical + Clean
Every tool should feel arcane and delightful, but never cluttered or confusing.

### 2. MVP First
Release the smallest useful version. Polish later.

### 3. Traffic Before Monetization
Monetization only works at scale. Getting discovered comes first.

### 4. Only Build What's Unique
We only build features that are unique or that deepen something already unique. There is no reason to replicate what established free tools already do well.

### 5. Sustainable Growth
Build tools that are maintainable, extensible, and can support future contributors and team members.

### 6. Community Value
The platform should genuinely empower DMs and players and help them run better sessions.

## Existing Code Commitment

This project contains working, live tools:

- React + Vite initiative tracker (live)
- Python + PostgreSQL spell API (live, 880+ spells)
- Spell Searcher frontend (live)

All development should reuse existing work, improve and refactor incrementally, and never assume a full rebuild without explicit discussion.

---

## Product Philosophy

The Site of Many Things should feel magical but clean, powerful but simple, delightful but fast, whimsical but professional.

We build tools that save time, spark creativity, reduce DM stress, improve session flow, and become weekly essentials for the people who use them.
