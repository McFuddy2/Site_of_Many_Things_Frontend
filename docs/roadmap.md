Where We Are
Two live, differentiated tools exist and no competitor matches either of them:

Initiative Tracker — the only one built for both players and DMs simultaneously
Spell Searcher — the most complete 5e spell search publicly available, and the only tool capable of filtering by class exclusion

The site has real users, real engagement (nearly 4 minutes average session), and a small but growing email list on Buttondown. Google has indexed 2 of 16 pages. Almost no one knows the site exists yet. That is the problem Phase 1 solves.
Glenn is employed as a data analyst, which removes emergency financial pressure. The goal is steady, sustainable growth toward meaningful supplemental income — not a frantic sprint.

The Strategic Filter
Before any feature gets scheduled, it must pass at least one of these two tests:

Does it extend or deepen a tool we already have that is already unique?
Is it itself something no other TTRPG site does well?

If the answer to both is no, it does not get scheduled.
Our two unique anchors:

The Spell Searcher — multi-class exclusion filtering no one else offers
The Initiative Tracker — built for players and DM simultaneously, with a live shared session model no other free tool provides

Sprints 4–6 | Estimated timeline: 2–3 months
The tools exist. The problem is that almost no one can find them.
Only 2 pages are indexed by Google. Zero organic search traffic arriving.
Phase 1 fixes this before adding any new features.
Primary goals:

Get all key pages indexed by Google
Publish 3 SEO articles targeting real search terms
Make the first genuine Reddit posts in TTRPG communities
Make Ko-fi and Buttondown signup visible on the site
Submit AdSense application
Complete mobile and tablet layout pass on both tools
Run full spell QC pass and add final source book (Heroes of Faerun)

Revenue expectation by end of Phase 1: $0–$50/month
Traffic expectation: 50–300 daily users if Reddit posts land well
What Phase 1 is NOT: a feature sprint. The tools are good enough. The job now is getting people to them.

Key Principles That Do Not Change

Only build what is unique, or what deepens something already unique
Build the chain — each feature makes the previous one more valuable
Traffic before monetization — ads and Ko-fi only work at scale
Tools first — content and generators support the tools, not replace them
Accounts before perks, perks before generators
Defer expensive features until revenue covers them
