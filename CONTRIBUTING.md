Contributing to The Site of Many Things
Thanks for your interest in contributing. This is a community-built TTRPG tool and we welcome thoughtful improvements.

What We Accept
Good contributions include:

Bug fixes
Accessibility improvements
Mobile and layout fixes
Performance improvements
UI polish that fits the existing magical aesthetic

When in doubt, open an issue first and describe what you want to change. That saves everyone time.

What We Do Not Accept

New features that have not been discussed first
Changes to the brand aesthetic without discussion
Backend contributions (the API is private)
Dependencies added without prior discussion


How to Contribute

Fork the repo
Create a branch named for your change, for example fix/mobile-spell-filter or improve/initiative-layout
Make your changes
Test locally with npm run dev
Open a pull request targeting main
Describe what you changed and why


Code Style

Keep components small and focused
Use existing CSS patterns before adding new ones
Comment anything that is not immediately obvious
Do not introduce TypeScript — the project is JavaScript


Deployment
Only the repo owner can merge to main and trigger a production deploy on Vercel. Your PR preview build will show as failed — this is expected on the Hobby plan and does not mean your code is broken.
